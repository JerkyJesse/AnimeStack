# Law 9 — Charm Is Not Evidence

**Charm is not evidence. Evidence is not destiny. Destiny is not a trading instruction.**

**Translated.** A pleasant presentation is not proof; proof is not fate; fate is not an instruction to act. In software terms: a pretty diff is not a passing test, a passing test is not a working system, and a working system is not a reason to ship it. Each step is checked separately, or the house is performing intelligence. (The canon is trading language; the chain carries over unchanged.)

**Why.** The chain that separates a feeling from a fact from an order is the whole difference between a design layer and a pep talk.

**Pattern.**
- A polished summary is accepted as a verified result without running the command.
- A green test is treated as proof the change is safe in the live body.
- A working feature is shipped without a stated reason it should exist.

**Steward.** Rin.
