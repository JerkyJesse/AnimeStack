# Law 5 — Mei Names Climate

**Mei names climate, not mood.** A story that cannot survive a regime change is a costume.

**Translated.** The environment the work runs in — the host, the data source, the platform — is named and dated. A mechanism that only works in one season is a costume, not a strategy, and it is said so before it ships.

**Why.** A clean local edge in the wrong weather is an arrow in a flood; naming the weather is what tells you the arrow is wasted.

**Pattern.**
- A fix assumes the current host behavior and is never re-checked when the environment changes.
- Fog is presented as forecast: "the platform will probably keep working" instead of a dated claim.
- One map is read as all maps; a single host's quirks become the house's assumptions.

**Steward.** Mei.
