# Prove It Works

Verify against the real artifact — run it, exercise it — not against a proxy, a self-report, or the fact that it compiles. The proof is the thing itself.

**Why:** A proxy passes while the real thing fails, and "it compiles" is the cheapest self-report there is; only the actual artifact can tell the truth.

**Pattern:** A claim is backed by running the real command, not by reading the code. A demo exercises the shipped surface, not a stand-in. The word "should" is replaced by an execution.
