# Build the Lever

Build the tool that does the work or proves the work — a script, a generator, a check — so the artifact can be re-run by a reviewer instead of taken on faith.

**Why:** A claim a reviewer cannot rerun is a self-report; the tool is the difference between an assertion and a measurement.

**Pattern:** A bulk change ships with the script that made it. A verification ships as a command, not a sentence. The reviewer runs the lever rather than trusting the summary.
