# Never Block on the Human

Proceed and present, then let the human course-correct. Pause for confirmation only at irreversible actions. Waiting is a second strategy nobody wrote down.

**Why:** A block on approval that was never required is delay dressed as caution; the human can correct a presented step, but cannot recover the time a question cost.

**Pattern:** Reversible work proceeds and is shown, not held for permission. Only an irreversible action — a spend, a delete, a publish — stops for confirmation. The default is forward motion with a checkpoint, not a gate.
