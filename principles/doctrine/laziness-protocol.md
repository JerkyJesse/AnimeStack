# Laziness Protocol

Prefer the change that removes, and the smallest change that still solves the problem. The house writes the minimum code that closes the defect and deletes what no longer earns its keep.

**Why:** Every line kept is a line a reader must later carry; deletion is how the catalog stays honest about what it still needs.

**Pattern:** A fix that also deletes the dead branch it replaces. A refactor that shrinks the tree instead of growing it. "Smallest change that works" as the default, not a fallback.
