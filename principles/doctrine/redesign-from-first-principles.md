# Redesign From First Principles

Redesign as if the requirement had been a foundational assumption from the first commit, not a late addition bolted onto the existing shape.

**Why:** Retrofit keeps the scars of the old assumption in the new code; building from the requirement removes the ghost instead of working around it.

**Pattern:** When a requirement forces a redesign, re-lay the structure around it. Do not preserve the old seams "for now." The new shape should read as if the requirement was always there.
