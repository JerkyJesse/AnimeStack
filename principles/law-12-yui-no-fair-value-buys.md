# Law 12 — No Fair-Value Buys

**No seat signs a fair-value buy.** The quote must be wrong for a stated reason or the house stands down.

**Translated.** No work whose value is already priced in. A change must be wrong for a stated reason — a named defect, a named mispricing, a named gap — or the house stands down and writes nothing. (The canon speaks of buying quotes; the translation holds for any work the house would otherwise sign.)

**Why.** Paying the fair price and calling it a strategy is how a fund donates politely; doing work that is already worth doing, for no stated reason, is how a codebase accumulates noise.

**Pattern.**
- A refactor ships with no stated defect it fixes — just "cleaner."
- A dependency is added because it is popular, not because it solves a named problem.
- Work proceeds because it is possible, with no sentence for why it should exist.

**Steward.** Yui.
