# Law 12 — No Work That Was Already Owed

**No seat signs work that was already owed.** The change must answer a stated failure, or the house stands down.

**Translated.** No change whose value is already obvious. Work gets a stated reason — a named defect, a named gap — or the house stands down and writes nothing.

**Why.** Paying full price for work everyone already agreed on is how a team confuses motion with judgment; doing work that was already owed, with no stated reason, is how a codebase accumulates noise.

**Pattern.**
- A refactor ships with no stated defect it fixes — just "cleaner."
- A dependency is added because it is popular, not because it solves a named problem.
- Work proceeds because it is possible, with no sentence for why it should exist.

**Steward.** Yui.
