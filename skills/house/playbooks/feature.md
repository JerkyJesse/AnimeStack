# Feature

## When

- "build this feature"
- "add a capability"
- a named failure exists and the second sample is not yet checked

## The loop

Lead: Reika then Yui.

- **Reika** — What are we building, in one sentence? FRAME: six forcing questions, then the mandate in one sentence — object, boundary, close. Produces the mandate.
- **Mei** — What change in the world makes this obsolete? Name the climate the feature must survive, and the blackout windows before the work starts. Produces the weather read.
- **Elo** — What does the crowd refuse to measure correctly? Name the sample and the metric that will say the feature worked. Produces the measurement plan.
- **Yui** — What failure does this prevent, and what would falsify it? BUILD: foundational data structures first, the feature from a named data shape, tests for the mechanism. Write the falsifier before the victory lap. Produces the build.
- **Niko** — Where does it live, and what must it never touch? The feature inhabits one module, one concern, no shared state. Produces the cage.
- **Rin** — How does this fail, and how fast? The failure in ordinary words, accepted or ended. Produces ACCEPT or END.
- **Aria** — What ships, and what triggers it? Run the tests; the feature goes into contact or stands down. Produces SHIP or STAND DOWN.
- **Reika** — What are we building, in one sentence? Close. `VERDICT: ...`.

## Gates

- The mandate is one sentence.
- The falsifier is written before the victory lap, with the sample, the window, and the persistence.
- Tests pass; no shared state; no work that was already owed.

## Close

Reika closes: `VERDICT: ...`. One sentence.

## Notes

No stated failure, no build. A feature that cannot name the gap it harvests is research with a `decide()` method. "The second sample can wait" is a line the house will not say twice.
