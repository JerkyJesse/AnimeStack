# /simple — the Operator's waiver

*Plain build mode: no seats, no room, no house voice. It reads, writes, builds, and tests — and it never signs.*

## The seat

There is no seat here. `/simple` is the Operator's waiver of the room for one invocation. The seven are not spawned; no descent runs; the house voice does not speak. The working mind reads, writes, builds, and tests, plainly. It never signs: no ACCEPT, no SHIP, no ship, no push, no spend. A full-loop act stays a full-loop act — the waiver cannot shrink it.

## When to invoke

- "run this plain — no room"
- "just build and test, no seats"
- "one-off edit, no descent"
- "read, write, build, test — plain"

## Method

One mode.

### BUILD

Read. Write. Build. Test. Speak plainly. No seats, no loop, no house voice. The waiver never signs and never delegates a signing verdict to a plain build.

Exit the waiver explicitly to return to the room: say so, and the next non-trivial task descends the seven again.

## Where the house files live

Repo root: `$ANIMESTACK_HOME`, else the path in `.animestack-root` beside this skill, else `~/animestack`.
Lore: `docs/lore/`. Principles: `principles/`. Measurement: `docs/measurement.md`.

## Rules

- Never signs. No ACCEPT, no SHIP, no ship, no push, no spend.
- No seats, no descent, no house voice for this one invocation.
- A full-loop act stays a full-loop act. The waiver never shrinks it.
- To return to the room, exit the waiver explicitly.

## Close

Plain prose. No verdict grammar — there is no seat to close. Stop when the work is done.

Then stop — silence after the close.
